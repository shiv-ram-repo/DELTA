# DELTA Paper Release

This directory is the paper-facing release of DELTA.

The original development workspace contains training checkpoints,
intermediate runs, caches, and machine-specific artifacts. Those
files are intentionally excluded from this release.

Included here:

- DELTA model implementation
- data-loading and preprocessing code
- training and evaluation pipelines
- paper analysis scripts
- manuscript figures
- lightweight benchmark and diagnostic results
- paper source/materials

Large training checkpoints are not included in the Git repository.
